接力 · 三 Claude 本机协作工作台
Windows x64 功能预览版 / 2026-10-23

先看这几步：
1. 在资源管理器中把 ZIP 全部解压到当前用户可写的、本地短目录。
   不要在压缩软件内直接运行，不要只拖出一个 CMD 或 HTML。
   建议整个 workbench 路径不超过 80 个字符，例如 D:\Apps\workbench。
   中文和空格可以用，但不要多层套目录；不要使用 Program Files、网络盘或同步目录。
2. 双击 start-workbench.cmd。它会启动本机后台并打开网页。
   不要双击 index.html：那只是明确标注的历史模拟，不调用真实 AI。
3. 双击 USER-GUIDE.html 阅读完整离线手册。
   首次在工作台阅读并自行决定是否同意当前随包条款。
4. 每位使用者自己安装并登录 Claude Code；不需要另装 Python、Node 或 Playwright。
   官方安装：https://code.claude.com/docs/en/setup
   自己在终端登录：claude auth login
   工作台不含 Claude、账号、密钥或免费模型额度，不代装、不代登录。
5. 网页点击“确认并准备测试浏览器”，确认后才从官方源下载约 173 MiB。
   准备完成后点击“重新检测（不调用模型）”，按提示处理登录或版本问题。
6. 新建项目 → 生成设计 → 下载修改 → 上传确认 → 拆分审核 → 手动开始。
   按钮不可用时看按钮下方的具体原因；登录未知且参数／依赖通过后，可自行确认使用已有本机配置。
   不要在另一浏览器只输入裸地址；会话失效时双击原CMD重开，不重启后台任务。
   “生成／拆分／开发／测试／返修／重试”会调用使用者自己的模型，可能计费。
7. 关闭网页不会退出后台。请等所有项目停稳，再点网页“退出工作台”。
   重复双击 CMD 只重开同一实例。移动或备份前先正常退出。

包内提供 Python 3.14.3、Node 24.14.0、Playwright/core 1.58.2、reason-network 0.10.8。
浏览器首次准备的固定版本：Chrome for Testing 145.0.7632.6 / revision 1208。
不含浏览器二进制、不含 userdata、不含任何人的 Claude 登录或业务项目。

重要边界：这是功能预览，不是“所有电脑、所有 Claude 配置已验收”的正式稳定版。
干净 Windows 和最新原生 Claude 流式／三岗位完整模型闭环尚未完成复验。
本机短目录的官方下载、校验、解压、浏览器自检及receipt已通过；深目录仍不支持。
失败不会自动重试。不要关闭 TLS、改摘要、删锁、手改数据库或提权强开。
本次已定位并修复并发启动空锁文件写入竞争，确定性回归及100组双进程通过；仍需保留其他启动错误诊断。
第三方通知保留，许可证完整性本轮未审核；不提供法律再分发结论。
